## Запуск приложения

### Предварительные требования
- [ ] Node.js установлен (версия 16 или выше)
- [ ] Доступ к серверу API (backend)
- [ ] Установлены все зависимости проекта

### Шаги запуска
1. [ ] Откройте терминал в директории проекта
2. [ ] Выполните команду `npm install` (если зависимости еще не установлены)
3. [ ] Запустите приложение командой `npm run dev`
4. [ ] Откройте браузер по адресу, указанному в консоли (обычно `http://localhost:5173`)

## Загрузка данных

### Обязательные файлы (необходимо загрузить все 3)

#### 1. Завоз/Вывоз
- [ ] Подготовьте Excel файл (.xlsx/.xls) с данными о завозе/вывозе
- [ ] Выберите тип данных "Завоз/Вывоз" в выпадающем списке
- [ ] Загрузите файл (перетащите или кликните на область загрузки)
- [ ] Введите название таблицы (например: "zvz_2024")
- [ ] Выберите нужный лист из файла Excel
- [ ] Нажмите "Сохранить выбор"
- [ ] Дождитесь подтверждения успешной загрузки

**Альтернатива:** Можете выбрать существующую таблицу из БД:
- [ ] Переключитесь на вкладку "Использовать существующую таблицу"
- [ ] Выберите таблицу из списка
- [ ] Нажмите "Сохранить выбор"

#### 2. RSS
- [ ] Выберите тип данных "RSS"
- [ ] Загрузите Excel файл с данными RSS
- [ ] Введите название таблицы (например: "rss_2024")
- [ ] Выберите лист
- [ ] Нажмите "Сохранить выбор"
- [ ] Дождитесь подтверждения

**Альтернатива:** Выбор существующей таблицы RSS

#### 3. Словарь
- [ ] Выберите тип данных "Словарь"
- [ ] Загрузите Excel файл со словарем
- [ ] Введите название таблицы (например: "dictionary_2024")
- [ ] Нажмите "Сохранить выбор" (лист выбирается автоматически)
- [ ] Дождитесь подтверждения

**Альтернатива:** Выбор существующих таблиц словарей:
- [ ] Выберите **ровно 3 таблицы** в следующем порядке:
  - Словарь RSS
  - Словарь Завоз/Вывоз
  - Словарь OV

### Опциональные файлы

#### 4. Остатки (необязательно, но рекомендуется)

**Вариант A: Выбор существующей таблицы**
- [ ] Выберите тип данных "Остатки"
- [ ] Перейдите на вкладку "Использовать существующую таблицу"
- [ ] Выберите таблицу остатков
- [ ] Нажмите "Сохранить выбор"

**Вариант B: Создание новой таблицы остатков**
- [ ] Убедитесь, что загружены все 3 обязательных файла (Завоз/Вывоз, RSS, Словарь)
- [ ] Выберите тип данных "Остатки"
- [ ] Перейдите на вкладку "+ Добавить остатки"
- [ ] Введите название таблицы остатков (например: "leftovers_jan_2024")
- [ ] Выберите дату (месяц/год)
- [ ] Для каждого состояния:
  - [ ] Выберите состояние из выпадающего списка
  - [ ] Введите значение (число больше 0)
  - [ ] Нажмите "Добавить"
- [ ] Повторите для всех необходимых состояний
- [ ] Проверьте список добавленных остатков
- [ ] Нажмите "Сохранить остатки"
- [ ] Дождитесь подтверждения

#### 5. Отгруз/Выгруз (опционально)
- [ ] Выберите тип данных "Отгруз/Выгруз"
- [ ] Загрузите Excel файл или выберите существующую таблицу
- [ ] Введите название таблицы (если загружаете новый файл)
- [ ] Выберите лист
- [ ] Нажмите "Сохранить выбор"

### Переход к анализу
- [ ] Убедитесь, что загружены минимум 3 обязательных файла (Завоз/Вывоз, RSS, Словарь)
- [ ] Проверьте индикаторы прогресса в верхней части (должны быть зеленые галочки)
- [ ] Нажмите кнопку "Перейти к анализу"
- [ ] Дождитесь загрузки страницы дашборда

## Работа с фильтрами

### Первоначальная загрузка данных
- [ ] На странице дашборда найдите панель фильтров слева
- [ ] Фильтры загружаются автоматически на основе загруженных таблиц
- [ ] Дождитесь окончания загрузки фильтров

### Настройка фильтров

#### Фильтр по датам
- [ ] Выберите начальную дату (Дата от)
- [ ] Выберите конечную дату (Дата до)

#### Фильтры по категориям
Для каждого типа фильтра доступны два режима:
- **IN (включить)** - показывать только выбранные значения
- **NOT IN (исключить)** - показывать все, кроме выбранных

**Источники (Sources)**
- [ ] Выберите режим (IN/NOT IN)
- [ ] Отметьте нужные источники в списке
- [ ] Или оставьте пустым для выбора всех

**Целевые (Targets)**
- [ ] Выберите режим (IN/NOT IN)
- [ ] Отметьте нужные целевые значения

**Диаметры (Diameters)**
- [ ] Выберите режим (IN/NOT IN)
- [ ] Отметьте нужные диаметры

**Типы (Types)**
- [ ] Выберите режим (IN/NOT IN)
- [ ] Отметьте нужные типы

**Состояния (States)**
- [ ] Выберите режим (IN/NOT IN)
- [ ] Отметьте нужные состояния

### Применение фильтров
- [ ] После настройки всех нужных фильтров
- [ ] Нажмите кнопку "Обновить диаграмму"
- [ ] Дождитесь загрузки данных (отображается индикатор загрузки)
- [ ] Проверьте, что все диаграммы обновились

## Анализ данных

### Диаграмма Sankey (основная диаграмма)
- [ ] Проверьте наличие диаграммы Sankey в центральной части экрана

- [ ] Изучите изменения показателей во времени
- [ ] Обратите внимание на легенду графика

### График накопительного баланса (Остатки)
- [ ] Прокрутите в самый низ страницы
- [ ] Найдите график накопительного баланса
- [ ] Анализируйте изменение остатков во времени
- [ ] Проверьте корректность отображаемых состояний

## Типичные проблемы и решения

### Проблема: Не отображаются данные после применения фильтров
**Решение:**
- [ ] Проверьте, что выбран хотя бы один элемент в каждом активном фильтре (если используется режим IN)
- [ ] Проверьте диапазон дат - возможно, в выбранном периоде нет данных
- [ ] Попробуйте сбросить фильтры и применить их заново

### Проблема: Ошибка при загрузке файла
**Решение:**
- [ ] Убедитесь, что файл в формате .xlsx или .xls
- [ ] Проверьте, что файл не поврежден
- [ ] Проверьте соединение с сервером API
- [ ] Попробуйте загрузить файл меньшего размера

### Проблема: Не удается перейти к анализу
**Решение:**
- [ ] Убедитесь, что загружены все 3 обязательных файла (Завоз/Вывоз, RSS, Словарь)
- [ ] Проверьте статус каждого файла (должны быть зеленые галочки)
- [ ] Если статус не меняется - попробуйте загрузить файл заново

### Проблема: Фильтры не загружаются
**Решение:**
- [ ] Проверьте параметры в URL (должны быть названия всех таблиц)
- [ ] Вернитесь на страницу загрузки
- [ ] Убедитесь, что все таблицы настроены корректно
- [ ] Повторите переход к анализу

### Проблема: График динамики не отображается
**Решение:**
- [ ] Убедитесь, что в выбранном периоде есть данные
- [ ] Проверьте настройки фильтров
- [ ] Попробуйте расширить диапазон дат

## Рекомендации по использованию

### Для эффективной работы с приложением:

1. **Подготовка данных**
   - [ ] Убедитесь, что Excel файлы корректно структурированы
   - [ ] Проверьте наличие всех необходимых столбцов
   - [ ] Удалите лишние строки и заголовки

2. **Именование таблиц**
   - [ ] Используйте понятные и уникальные названия
   - [ ] Добавляйте дату или период в название (например: "zvz_jan_2024")
   - [ ] Избегайте спецсимволов и пробелов

3. **Работа с фильтрами**
   - [ ] Начинайте с широких фильтров, затем уточняйте
   - [ ] Используйте режим NOT IN для исключения выбросов
   - [ ] Сохраняйте скриншоты важных отфильтрованных данных

4. **Анализ данных**
   - [ ] Регулярно экспортируйте данные для создания отчетов
   - [ ] Сравнивайте разные периоды с помощью графика динамики
   - [ ] Используйте Sankey диаграмму для визуализации основных потоков

5. **Производительность**
   - [ ] Не загружайте слишком большие файлы (рекомендуется до 50 МБ)
   - [ ] Используйте существующие таблицы для повторного анализа
   - [ ] Периодически очищайте старые таблицы из БД
